# Задворка 2026

Сайт-воспоминание о летнем отдыхе 2026 года.

## Технологии

- React 19
- TypeScript
- Vite
- React Router (HashRouter)

## Установка и запуск

```bash
npm install
npm run dev        # режим разработки
npm run build      # production-сборка
npm run preview    # предпросмотр сборки
```
